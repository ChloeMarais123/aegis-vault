# Contributing to AEGIS VAULT

Thanks for wanting to help harden the vault!

## How to Contribute
1. Fork the repo
2. Create a branch: `git checkout -b feat/my-feature`
3. Test in browser (just open index.html)
4. Commit: `git commit -m 'feat: my feature'`
5. Push & open PR

## Guidelines
- Keep it vanilla JS — no heavy frameworks
- No external dependencies for crypto (use Web Crypto API only)
- Preserve offline-first & zero-knowledge principles
- Add tests in docs if you add crypto logic
- UI stays Obsidian Core theme (cyan/gold/green on #060a0f)

## Commit Convention
- feat: new feature
- fix: bug fix
- sec: security improvement
- docs: documentation
